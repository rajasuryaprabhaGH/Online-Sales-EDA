# Online Sales Exploratory Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on an online sales dataset to understand sales patterns, revenue trends, correlations, and key influencing factors.

## Analysis Performed
- Statistical summary
- Revenue by product category
- Monthly revenue trend
- Correlation analysis
- Revenue by region
- Payment method analysis
- Key insights

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Conclusion
The analysis provides insights into online sales performance, revenue trends, product categories, regional performance, and relationships between sales variables.
